# Jiho personal mark

Created for Jiho Jang's portfolio on 2026-11-08. This is an original SVG mark drawn for this site.

The design follows a recurring theme in the portfolio: turning inputs into working systems. Mechanical design and robotics, data processing and automation, and story-agent development all connect information to a useful action.

- **J:** the initial of Jiho and Jang, drawn as one continuous path.
- **Rounded path:** a flow from data through processing to movement or an application; also recalls a planned robot trajectory.
- **Orange starting point:** the input that starts the flow, using the portfolio's existing accent color.
- **Dark tile and light stroke:** contrast that stays legible at the small sizes used in the header and favicon.

The master file is `public/media/brand/jiho-mark.svg`, with a 32×32 viewBox. The header uses it at 32px and the hero at 24px. `public/favicon.svg` is an identical copy for browser tabs. Both languages and every project header use the same asset. The repeated page marks are decorative because the adjacent text already identifies the owner and subject.
