- 기존 KT 경력을 Data Scientist로 변경하고 설명·부서 이력을 보강. 시작일은 포트폴리오에 근거하여 2022년으로 수정. 정확한 입사 월은 확인 요청 상태이며 비워둠.
- KT 인턴(2021–2022)과 경북대학교 학부연구생(2021) 경력 등록. 확인되지 않은 월은 비워둠.
- 학력의 전공을 기계공학부로 정리하고 ROBO 회장·연구·프로젝트 활동 추가.
- 프로젝트 6개 등록. 학교 프로젝트 3개는 학력에, 회사 프로젝트 2개는 KT 경력에 연결. 주문 자동화는 개인 프로젝트로 등록하고 현재 진행 중으로 설정.
- 제1저자 논문 1건 및 원문 PDF 링크 등록. 정확한 발표일은 비워두고 설명에 확인된 2021년 명시.
- 원본 상장 이미지의 수상자·기관·날짜를 직접 대조한 뒤 수상 2건 등록.
- 연락처 웹사이트에 한국어 포트폴리오를 포트폴리오 유형으로 등록.
- 경력·학력 변경의 인맥 알림은 해제 상태로 저장.
- 프로젝트 6개, 경력 3개, 논문, 수상 2건, 학력, About과 대표 기술의 실제 LinkedIn 표시를 확인.
- 스페셜 등록에서 주문 자동화 상세 링크와 포트폴리오 메인 링크 모두 ‘미리보기를 생성할 수 없었습니다’ 오류가 발생하여 저장 불가. 포트폴리오는 About·연락처·프로젝트 설명을 통해 제공.

## 소개 (About)

데이터를 분석하고, 그 결과를 실제 업무에 쓰이는 도구로 연결하는 Data Scientist입니다. 현재 KT AX Data Lab에서 데이터 처리와 업무 자동화를 다루고 있습니다.

저는 복잡한 데이터를 정리하는 일부터 분석 로직, 성능 최적화, 사용자가 결과를 탐색하는 화면까지 하나의 흐름으로 구현하는 데 관심이 있습니다. 반복적인 수작업을 줄이고, 데이터를 통해 업무를 더 빠르고 명확하게 수행할 수 있도록 돕습니다.

• 차량 데이터 분석 및 성능 개선
초 단위 차량 운행 기록과 보험 사고 이력을 연결해 운전행태를 비교하는 데이터 처리·분석 코드를 개발했습니다. Excel 기반 반복 업무를 Python으로 자동화하고, 핵심 반복 계산을 pandas 연산으로 전환해 당시 처리속도를 11배 개선했습니다.

• Palantir Foundry 기반 데이터 애플리케이션
통신 이벤트 전처리와 위치 정보 가공, Ontology 연결, Workshop UI/UX를 구현했습니다. 이상 징후 후보의 근거를 확인하고 시간에 따른 이동 이력을 탐색할 수 있도록 구성했습니다. 공개 포트폴리오에는 더미데이터 기반 PoC를 소개하고 있습니다.

• 주문·재고 업무 자동화
개인 프로젝트로 고객 요구사항 정의부터 프론트엔드, Python 백엔드, ERP API 연동, 데이터 처리까지 전 과정을 혼자 개발하고 있습니다. 최대 16개 동시 API 요청과 캐시 재사용, 집계 자동화를 통해 사용자 경험 기준 약 하루 걸리던 주문 확인·정리 업무를 3분 이내로 단축했습니다. 주문 조회·주별 집계·Excel 출력·재고 입력을 구현했으며, 생산계획 최적화는 다음 개발 단계입니다.

기계공학과 로봇 개발에서 출발한 경험은 데이터를 실제 시스템의 동작과 연결해 생각하는 기반이 되었습니다. 학부에서는 비전 기반 드론 편대비행을 연구하고, 2021년 제2회 한국 인공지능 학술대회에 제1저자로 논문을 게재했습니다.

관심 분야: 데이터 분석, 데이터 엔지니어링, 업무 자동화, 로보틱스·자율 시스템
