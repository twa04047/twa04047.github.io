# 델타로봇 포트폴리오 자료 근거

## 개인 기여와 서술 범위

사용자는 이 대화에서 델타로봇의 CATIA 기반 CAD 설계와 로봇 부속품의 설계·제작을 직접 담당했다고 확인했다. 2020년 연구팀 신청서의 분담표에도 장지호의 역할이 아이디어 창출, 설계 및 제작으로 기록되어 있다. 이를 개인 기여의 기준으로 사용했다.

영상처리, 역기구학, Python 패킷 생성 및 모터 제어는 팀 시스템으로 설명한다. 해당 코드를 사용자가 단독 개발했다고 서술하지 않는다. 구매 모터와 조인트까지 직접 제조했다는 의미로 확대하지 않는다.

## 공개 미디어

`public/media/delta/`에는 다음 파일만 선별했다.

- `delta-cad.jpg`: 사용자가 지정한 `Delta.jpg` 원본 복사.
- `final-demo.mp4`: 최종시연영상 전체 원본 복사. SHA-256으로 원본과 동일한 파일임을 확인했다.
- `gantry-design.pdf`, `conveyor-drawing.pdf`: 원본 설계 메모·도면 복사.
- `prototype.jpg`, `motor-mount.jpg`, `robot-detail.jpg`, `vision-screen.jpg`: 최종 발표자료에 포함된 실물 사진을 웹용 JPEG로 변환.
- `cad-assembly.jpg`, `assembly-in-progress.jpg`, `workspace.jpg`: 이전 발표 버전에 포함된 CAD 화면·제작 사진·작업영역 그림.
- `conveyor-cad.jpg`, `conveyor-prototype.jpg`: 수정4 발표자료의 컨베이어 설계 및 제작 이미지.
- `gantry-sketch.jpg`: 원본 프레임 설계 PDF의 렌더링.
- `innovation-award.png`: 사용자가 제공한 `F:\상장\se-knu혁신상.jpg`에서 상장 영역을 잘라 90도 회전한 사진. EXIF 방향을 적용한 뒤 정수 좌표로 자르고 픽셀을 90도 전치했다. 1820×2448 픽셀의 PNG로 무손실 저장했으며, 저장 후 원본 크롭 영역과 픽셀이 일치함을 확인했다. 글자 수정·생성, 원근 보정, 축소, JPEG 재압축은 적용하지 않았다. 혁신상, 수상 과제, 수여 기관 및 2020년 11월 13일 수상 일자는 이 상장을 근거로 추가했다.

발표자료에서 추출한 사진은 형식 변환과 종횡비를 유지한 축소만 적용했다. 공개 미디어에는 합성 이미지나 새로 생성한 제작 결과를 포함하지 않았다. 영상의 0:00, 2:00, 4:40 구간 링크는 원본 영상을 같은 플레이어에서 탐색한다.

신청서, 회의록 원본, 거래명세서, 구매 목록은 맥락 확인에 사용하고 사이트에 복사하지 않았다. 연락처·서명·정산 자료를 공개 콘텐츠에 포함하지 않았다.

## 전체 폴더 검토 범위

실제 보관 폴더에서 147개 파일의 경로·크기·해시를 확인했다. 폴더 내 파일끼리 중복을 제외한 내용은 101종이며, 중복 ZIP 내부 항목은 풀려 있는 파일과 해시로 대조했다. 7개 PPTX, 7개 HWP, 5개 PDF, 3개 XLSX, Python·MATLAB·C·텍스트, 이미지와 동영상을 분류·추출해 확인했다. 발표자료 내부를 포함한 고유 이미지 93개와 영상 8개도 확인했다.

CATPart·CATProduct·CATDrawing과 HFB는 전용 CAD/프린터 애플리케이션에서 재실행하지 않았다. 파일 구조·목록과 제공된 렌더링, 제작 도면 및 실물 사진을 대조했다. STL은 파일 구조와 삼각형 데이터를 확인했다. CAD의 모든 피처 이력이나 어셈블리 구속조건을 재검증한 것은 아니다.

`Delta.rar`의 MATLAB 예제는 풀려 있는 소스에서 검토했다. `main.m`의 외부 저작자 표기를 고려하여 해당 예제를 개인 개발 성과로 쓰지 않았다. `DeltaKin.pdf`와 `Delta Robot.pptx`는 역기구학 참고 자료로 구분했다. `last.zip`의 C 소스 등 최종 델타로봇 시스템과 직접 연결이 확인되지 않은 자료와 구매 시점·용도가 불명확한 추가구매 목록은 성과에 포함하지 않았다.

## 버전 차이와 검증 한계

- 이전 발표에는 Hough 원 검출, 최종 발표에는 이진화·윤곽선 기반 검출이 나온다. 포트폴리오는 최종 발표와 해당 OpenCV 소스를 기준으로 후자를 설명한다.
- `최종 코딩/loop_v1.py`는 `VisualSensor.circle_data()`를 호출하지만 같은 폴더의 `VisualSensor.py`에는 해당 함수가 없다. 함수가 있는 윤곽선 버전은 `delta code/VisualSensor.py`에 존재한다. 보관 폴더를 현재 환경에서 곧바로 실행 가능한 완성 패키지라고 주장하지 않는다.
- 초기 목표에는 자율 이동과 다양한 농작업이 포함되지만, 최종 영상에서 확인되는 실내 시제품과 동작 범위만 결과로 서술한다.
- 델타로봇의 일반적 고속·고정밀 특성, 모터 제조사 사양, 계획서의 기대효과를 이 시제품의 실측 성능으로 바꾸지 않는다.
- 현장 제초율, 반복 위치 정밀도, 가동 시간·수명, 내구성의 실측 자료는 확인되지 않았다.

추출 텍스트, 상세 파일 목록, 검토용 이미지와 보조 스크립트는 Git에서 제외된 `private/delta-research/`에 보관한다.
