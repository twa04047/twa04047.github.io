# 모범시민 교통관제 로봇 자료 근거

## 프로젝트와 개인 기여

- 2020년 경북대학교 재학 중 장지호·이재건 2인 팀 모범시민이 제안한 교통관제 모바일 로봇.
- 사용자가 개인 역할을 **비전 개발**로 확인했다. 원본 배너에는 장지호가 팀장으로 표기되어 있으나, 포트폴리오의 역할 설명은 사용자가 확인한 개발 영역을 중심으로 작성했다.
- 분류: 학교 프로젝트, 아이디어·PoC 제작. `stage: "idea-poc"`를 추가해 Foundry의 `poc`(더미데이터 PoC)와 구분했다.
- 기구 설계·하드웨어 제작·레일 이동은 팀 결과로 서술한다. 사용자의 단독 설계·제작 성과로 확대하지 않는다.

## 해석과 버전 차이

- 추가 영상 확인 전에는 발표자료의 실내 얼굴 검출과 시제품 사진만 근거로 삼았다. 추가된 비전 영상에서 차량 검출을, 모터 영상에서 레일 이동을 확인하고 최종 본문과 증빙 범위를 확장했다.
- 얼굴 검출은 기존 OpenCV Haar Cascade 적용이다. 실행 화면에 `PinkWink test`라는 예제 흔적이 있어 독자 검출 알고리즘이나 직접 학습한 모델로 서술하지 않는다. 원본 `face.py`나 차량 검출 소스는 지정 폴더에 없다.
- 차량 검출 모델명·버전·학습 방식·데이터셋은 영상만으로 확정할 수 없다. 차량 검출을 Haar Cascade로 수행했다거나 특정 YOLO 버전을 사용했다고 주장하지 않는다.
- 검출 박스 위의 신뢰도 점수는 정확도 지표가 아니다. 정량적인 성능 수치, 프레임률 실측, 오검출률을 추가하지 않았다.
- 보행자 위험 판단, 번호판 인식, 문자 발송, 운영센터·GPS·ITS 연계, 무선충전 및 도시 규모 운영은 제안·확장 목표다. 시연 두 개를 하나의 통합된 자율 관제 시스템의 검증으로 해석하지 않는다.
- 모터 영상 컨테이너에는 2020-11-30 생성 시각이 있으므로 이를 11월 25일 본선 현장 촬영이라고 단정하지 않는다. 원본 메타데이터 자체도 촬영 날짜의 확증으로 쓰지 않는다.
- 초기 발표의 비용 절감 예상치와 뉴스·교통통계는 실측 성과가 아니다. 최종 발표 마지막 장의 미래 뉴스 형식 그래픽도 실제 운영 실적으로 쓰지 않았다.
- `모범시민_영상.mp4`(약 9.71초), `모범시민_영상2.mp4`(약 9.58초)는 KTV 교통문제 뉴스 발췌본이다. 프로젝트 시연으로 첨부하지 않았다.

## 공개 미디어

`public/media/traffic/`:

- `robot-cad.jpg`, `rail-cad.jpg`: 원본 JPEG 복사.
- `vision-demo.png`, `prototype.png`, `use-scenario.png`: 최신 발표자료 PPTX에 포함된 PNG를 그대로 추출. 합성·수정 없음.
- `presentation.pdf`, `banner.pdf`: 원본 발표자료 16쪽과 배너 1쪽 복사.
- `excellence-award.jpeg`: 사용자 제공 상장 원본 그대로 복사. 크롭·회전·문자 수정·재압축 없이 EXIF 방향을 브라우저가 적용한다.
- `vision-demo.mp4`: MPEG-4 Part 2 원본을 브라우저 호환 H.264/yuv420p로 변환하고 faststart 적용. 원본 전체 길이와 1920×1060 해상도 유지. 원본에 음성 없음.
- `vision-demo-original.mp4`: 비전 영상 원본(29,373,065 bytes). 원본과 SHA-256 일치.
- `motor-demo.mp4`: 모터 영상 원본(2,298,022 bytes). 원본과 SHA-256 일치. 세로 회전 메타데이터와 현장 음성 유지.
- `vision-poster.png`, `motor-poster.png`: 각 영상의 2초 시점 프레임 추출. 영상 화면을 생성하거나 덧그리지 않음.

비디오 플레이어는 `preload="none"`으로 두며 자동 재생하지 않는다. 상세 페이지에는 두 시연을 직접 재생할 수 있는 플레이어와 원본 자료 링크를 제공한다.

## 전체 폴더 검토 범위

실제 보관 경로에서 추가 영상 2개를 포함해 **86개 파일**의 경로·크기·SHA-256을 확인했다. 파일 내용 기준 중복을 제외하면 62종이다. ZIP 4개의 모든 내부 파일은 풀린 자료와 해시가 일치했다.

PPTX 6종의 본문·발표자 노트·관계 파일·내장 미디어, PDF 6종, HWP 3종을 추출해 비교했다. 발표자료 PDF 16쪽과 배너·가이드를 렌더링해 확인했다. 내장 이미지와 별도 렌더링을 포함한 이미지 목록 52개, 고유 영상 4개를 검토했다. 3개 WMF는 PPTX 내부 자료와 중복이다.

CATIA·SolidWorks·DWG와 확장자 `.2`인 설계 파일은 파일 목록·형식과 제공된 렌더링 및 사진을 대조했다. 네이티브 CAD 애플리케이션에서 모든 피처·어셈블리 구속조건·도면을 재실행하지 않았다. STEP의 헤더·형식과 Creo 로그도 확인했으나 새로운 구조해석 결과로 사용하지 않았다.

전체 파일 목록, 해시, 추출 텍스트, 렌더링, 프레임과 검토 스크립트는 Git에서 제외된 `private/traffic-research/`에 보관한다. 원본 폴더는 읽기만 했다.
