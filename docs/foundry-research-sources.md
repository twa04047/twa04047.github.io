# Foundry 이동형 셀 모니터링 PoC 자료 검토

## 탐색 범위

사용자가 지정한 `palantir/_femto` 경로는 현재 존재하지 않았고, 같은 Projects 폴더의 `palantir_femto`에서 해당 자료를 확인했다. `.git` 내부를 제외한 67개 파일을 목록화하고 형식별로 검토했다. 원본 폴더는 수정하지 않았다.

| 자료 | 수량 | 검토 방식 |
| --- | ---: | --- |
| Python 소스 | 10 | 위치 추적, 시간 조인, 구간 집계, 좌표 변환, 지도 출력과 주소 캐시 구조 확인 |
| Notebook | 3 | 셀 소스 추출, 분석 목적과 출력 블록 유무 확인. 셀 실행 없음 |
| CSV | 6 | 헤더·구분자·행 수 확인. 원시 레코드 공개 제외 |
| Excel | 11 | 모든 시트의 헤더·범위·행 수 확인. 데이터 공개 제외 |
| 지도 HTML | 23 | 각 파일의 지도·마커·선·팝업·GeoJSON 구성 확인. 원본 공개 제외 |
| PowerPoint | 3 | 전체 29개 슬라이드 텍스트와 삽입 미디어 목록 추출 |
| 이미지 | 6 | Foundry 캡처 4종과 행사 이미지 2종 직접 확인 |
| 영상 | 1 | Chrome에서 재생, 경로·타임라인 장면 확인. 약 32.576초, 1684 × 906 |
| GeoJSON | 1 | 행정구역 FeatureCollection과 속성 구조 확인 |
| 텍스트 및 확장자 없는 데이터 | 2 | 내용 형식 확인. 식별자 데이터 공개 제외 |
| Git ignore 설정 | 1 | 자료 폴더의 제외 규칙 확인 |

상세 목록·파일 해시·추출 내용은 Git에서 제외되는 `private/foundry-review/`에 보관한다. 해당 폴더와 `qa/`는 사이트 빌드에 포함되지 않는다.

## 게시한 자료

`public/media/foundry/`에는 PoC 이미지 4종, 원본 경로 시연영상 1종, 관련 협업 발표 사진의 모자이크 편집본 1종과 WIS 시연 사진 1종을 게시했다. 발표 사진은 사용자의 후속 요청에 따라 편집했으며, 원본은 자료 폴더에 보존했다. 나머지 사진과 영상은 원본 그대로 사용한다.

- `route-explorer.png`: 경로 탐색 화면
- `flag-monitoring.png`: 이상 플래그 모니터링 화면
- `data-lineage.png`: 모니터링 데이터 흐름
- `pipeline-builder.png`: 전처리 구성
- `route-demo.mp4`: 약 33초, 17,805,054바이트의 원본 시연영상
- `poc-presentation-mosaic.png`: 별도 KT × Palantir PoC 경험 공유 사진. 사용자가 본인이라고 밝힌 가운데 흰 옷의 참석자는 모자이크하지 않고, 왼쪽 발표자와 오른쪽 참석자의 얼굴에 모자이크를 적용했다. 공개 폴더에서 모자이크 전 파일을 제거했다.
- `wis-demo.jpeg`: 사용자가 추가 게시를 요청한 WIS 시연 사진. 원본의 “AI-generated content” 워터마크를 포함해 그대로 보존했다.

WIS 사진은 최초 검토에서는 워터마크 때문에 제외했으나, 후속 요청에서 사용자가 WIS 시연 사진임을 확인하고 추가 게시를 지시해 반영했다. 행사 사진을 이동형 셀 PoC의 성능 검증 근거로 사용하지 않는다. 원시 CSV·Excel·Notebook·지도 HTML·소스 및 내부 리소스 식별자가 포함된 PPTX는 계속 비공개로 유지한다.

### 발표 사진 편집 기록

내장 imagegen 도구를 사용했다. 편집 지시는 “가운데 흰 옷을 입은 참석자의 얼굴과 원래 구도를 유지하고, 왼쪽 검은 옷 발표자와 오른쪽 안경 쓴 참석자의 얼굴에만 강한 사각 모자이크를 적용한다”였다. 결과에서 두 얼굴의 모자이크와 가운데 참석자의 비모자이크 상태를 시각적으로 확인했다. 생성형 이미지 편집이므로 원본과의 픽셀 단위 동일성은 주장하지 않는다.

## 표기와 제한

- 한·영 카드에 더미데이터 PoC 상태를 표시하고, 상세 페이지 상단에 기밀·공개 범위를 명시했다.
- 화면 수치와 좌표는 예시 데이터이며 실제 운영 결과 또는 실측 성과로 표현하지 않았다.
- 경로 선은 관측·집계 위치를 연결한 표현이다. 도로 주행 경로나 GPS 수준의 정확도를 주장하지 않는다.
- 자료에 없는 날짜, 탐지율, 오탐률, 속도 개선 수치와 사업 성과를 추가하지 않았다.
- 기존의 재직 5년차 표기를 유지했다. 파일명과 화면의 예시 날짜를 프로젝트 수행 기간으로 사용하지 않았다.
- 로컬 자료로 사례 설명에 필요한 근거가 확보되어 사용자가 제시한 인증 필요 Foundry 링크에 추가 접근하지 않았다. Chrome은 로컬 시연영상과 포트폴리오 화면 확인에 사용했다.
