# UBI 포트폴리오 근거 기록

확인일: 2026-09-25. 원본 위치: 별도 로컬 `ubi_project` 작업공간. 이 문서와 사이트에는 실제 차량 ID, 행 데이터, 보험정보를 기록하지 않는다.

## 기여와 성능

- 사용자 제공: Excel 기반 작업의 Python 자동화, 일반 for문 기반 핵심 계산의 pandas 전환, 당시 처리속도 11배 개선.
- 11배는 사용자 확인 성과이다. 과거 벤치마크의 입력 범위, 하드웨어, 절대 실행시간을 새로 확인하거나 재현한 것은 아니다.
- 상대 처리시간은 기존 100, 개선 후 `100 / 11 ≈ 9.1`; 감소율은 `1 - 1/11 ≈ 90.9%`로 환산한다.
- 보관 코드에는 파일·트립 순회 반복문이 남아 있으므로 모든 반복문을 제거했다는 표현은 사용하지 않는다.

## 데이터 전수 집계

`ubi_data/csv_data`의 모든 CSV를 읽어 헤더를 확인하고 본문 행을 센다. 따옴표가 있는 파일은 CSV 파서로 계수한다. 익명 ID나 원본 레코드는 출력·복사하지 않는다. 행 수는 중복 제거 전의 저장 레코드 수다.

| 항목 | 결과 |
| --- | ---: |
| CSV 파일 | 10,000 |
| 헤더 제외 행 합계 | 252,781,483 |
| 총 바이트 | 23,241,441,274 |
| 십진 GB | 23.241441274 |
| GiB | 21.645278925 |
| 헤더 제외 평균 바이트/행 | 91.938226638 |
| 데이터 컬럼 | 13 |
| 저장용 인덱스 열 | 1 |
| 같은 헤더를 가진 파일 | 10,000 |

별도 `parquet_data`에는 501개, 7,786,556,233바이트가 있다. CSV와 관측 범위/중복 관계를 검증하지 않았으므로 행 수에 합산하지 않는다. `mapping_data`의 1개 파일도 운행 레코드 집계에서 제외한다. 보관 CSV 범위를 전체 프로젝트의 총 처리량이나 완전한 한 달 데이터로 단정하지 않는다.

13개 컬럼: `VIN`, `TRIP_DATE`, `TRIP_COUNT`, `TRIP_TIME`, `RPM`, `SPEED`, `DIRECTION`, `ACCEL_X`, `ACCEL_Y`, `BRAKE_YN`, `DAY_DISTANCE`, `TOTAL_DISTANCE`, `STATUS`.

## 월간 규모 가정

- 1초에 1행, 30일, 누락·중복 없음. 기록시간은 하루 24시간 또는 8시간.
- 행 수 = 차량 수 × 하루 기록시간 × 3,600 × 30.
- CSV 용량 = 행 수 × 약 92바이트 ÷ 1,000,000,000 GB.
- 1대·24시간: 2,592,000행, 약 0.238GB.
- 1대·8시간: 864,000행, 약 0.079GB.
- 500대·8시간: 432,000,000행, 약 39.744GB.
- 실제 운행시간, 값의 자릿수, 인덱스, 압축·저장 형식에 따라 용량은 달라진다. CSV의 평균 행 크기로 Parquet 용량을 추정하지 않는다.

## 코드 근거

| 보관 경로 | 확인 내용 |
| --- | --- |
| `ubi_origin_data_extraction/DTG_data_parsing_v4_modified.py` | 고정 길이 원문 파싱, 익명 시리얼 ID, 13개 출력 컬럼, 브레이크 ASCII 코드 |
| `ubi_total_data_processing_v2/UBI_duration_calculator.py` | 트립별 처리, `diff`, `rolling`, `shift`, 불리언·NumPy 조건식 |
| `ubi_total_data_processing_v2/UBI_trans.py` | 차량별 `groupby`, 노출량 보정, 표준화·IQR 이상치 처리, Excel 출력 |
| `insurance_data_processing/insurance_data_trans_mapping_data_include.py` | 여러 보험 Excel 시트 처리, 날짜·소유 기준 필터, 사고회수·보험금 집계, 시리얼 매핑 |
| `ubi_total_data_processing_v2/UBI_t_test_calculator.py` | 보험정보가 연결된 차량에서 사고회수 0 / 양수로 집단 분리, F검정 후 독립표본 T-Test |

F검정·T-Test는 집단 비교 단계다. 사고 이력에 따른 집단 구분과 개별 차량의 사고 예측 모델을 혼동하지 않는다. 모델 정확도나 보험사 실제 도입 성과를 임의로 추가하지 않는다.
