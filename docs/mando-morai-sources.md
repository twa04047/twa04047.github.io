# 만도 자율주행 시뮬레이션 대회 포트폴리오 근거

## 출처와 개인 기여

원본은 현재 `F:\만도_모라이_자율주행대회`에 보관되어 있다. 폴더에는 대회 계획·강의자료, 팀원별 ROS 코드, 지원 라이브러리와 `results/`의 사진·영상이 섞여 있다. 대회 부문은 계획안의 **Autonomous Driving Simulation Challenge**다. 이 사이트에서는 사용자의 요청에 따라 **교외 프로젝트**로 분류한다.

`src/jiho`의 코드를 `docs/강의 자료/aMAP_ch910_skeleton.zip_압축해제`와 비교해 개인 변경과 제공 예제를 나눴다.

| 코드 | 확인한 범위 |
| --- | --- |
| `lane_binarize.py` | 제공 예제의 HSV 변환 대신 BGR에 다른 임계값 적용 |
| `lane_roi.py` | 640×480 ROI 조정, 마스크 비율 계산, `school_zone` Bool 토픽 발행 추가 |
| `velodyne_parser.py` | LiDAR 점 선택 조건 변경 |
| `velodyne_parser_yolo.py` | 별도 전방 거리 실험본. YOLO 추론 호출은 없음 |
| `lane_bev.py`, `ex_calib_velodyne.py`, `pedes_detector.py` | 제공 스켈레톤과 동일 |
| `velodyne_cluster.py` | 실행기만 Python 3으로 변경; 나머지 강의 예제와 거의 동일 |

`src/EH/morai_camera_node`, `morai_gps_imu_node`, `src/hyunho`에는 차선 곡률·GPS/IMU 경로 추종·명령 통합의 팀 작업본이 있다. Velodyne 드라이버, MORAI 메시지·지도 유틸리티, 강의 ZIP은 개인 독자 개발로 표기하지 않는다. 원본 `PORTFORIO.MD`와 `docs/코드출처와검증.MD`에도 동일한 구분을 기록했다.

## 공개 미디어 대응표

원본의 `results/` 파일을 내용 수정 없이 `public/media/mando/`에 복사했다.

| 공개 파일 | 원본 파일 | 확인한 내용 |
| --- | --- | --- |
| `lane-photo.jpg` | `만도_자율주행_라인.JPEG` | MORAI 곡선 도로·가상 차량, 차선 처리 창, 조향 로그가 함께 보이는 사진 |
| `rgb-filter-photo.jpg` | `만도_자율주행_RGB필터.JPEG` | 시뮬레이터와 영상 필터 결과·터미널을 함께 촬영한 사진 |
| `lane-tracing-demo.mp4` | `시뮬레이션_라인트레이싱_테스트.mp4` | 파일명상 라인트레이싱 테스트. Windows 미디어 속성의 길이는 약 8초, 1870×1024, H.264 |
| `simulation-test.mp4` | `만도_자율주행_테스트.MP4` | 파일명상 자율주행 테스트. Windows 미디어 속성의 길이는 약 1분 1초, 852×480, H.264 |

두 사진은 화면을 확인했다. 영상은 파일·미디어 속성을 확인해 원본을 게시했으며 **장면별 내용이나 완주 여부를 별도로 판독하지 않았다**. 따라서 상세 페이지의 영상 설명은 파일의 성격과 길이에 한정한다. 원본 대회 PDF/PPTX와 외부 ROS 패키지는 재배포 조건을 확인하지 않아 사이트에 복사하지 않았다.

## 해석과 한계

- 대회 계획안은 예정 일정과 과제 범위를 설명하며 개인의 참가 단계·성적·수상을 입증하지 않는다.
- 색상 기반 스쿨존 판단은 표지판 또는 신호등 인식 모델이 아니다. 강의의 신호등 인지 주제만으로 구현 성과를 주장하지 않는다.
- LiDAR 전방 각도 필터는 두 조건을 연결해 의도한 교집합보다 넓은 범위를 포함할 수 있고, 빈 입력 처리도 부족하다.
- 사진·영상은 시뮬레이터 실험 장면의 기록이다. 성공률·처리속도·정확도·대회 완주를 측정한 자료는 없다.
- 당시 ROS/MORAI 환경을 현재 다시 실행한 통합 테스트는 수행하지 않았다.
