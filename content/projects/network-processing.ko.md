## 해결한 문제
네트워크 이상감지 과제에서 IP 주소가 특정 CIDR 대역에 포함되는지 탐색하는 전처리 과정을 개선했습니다. 전체 시스템 중 제가 맡은 범위는 이 탐색 과정의 최적화입니다.

## 직접 구현한 부분
IP와 서브넷 대역의 포함 관계를 찾는 과정에 **이진탐색과 Numba**를 적용했습니다. 과제에서는 Python과 PySpark를 사용했습니다.

- 개선 대상: CIDR 대역 포함 여부 탐색
- 접근 방법: 이진탐색을 활용한 탐색 과정 개선
- 실행 최적화: Numba 적용

정확한 자료구조와 적용 순서는 기존 코드를 확인한 뒤 설명을 보완할 예정입니다.

## 기여 범위와 검증
이 경험에서 설명하는 기여는 **전처리 탐색 최적화**입니다. 이상감지 모델 자체를 개발했다는 의미는 아닙니다.

처리 시간의 전후 비교, 입력 규모와 실행 환경, 최적화 이후 결과의 일치 여부는 당시 코드와 기록을 확인한 후 추가합니다. 아직 확인하지 않은 성능 수치는 제시하지 않았습니다.
