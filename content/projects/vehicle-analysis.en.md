## Project context
I analyzed large-vehicle data, including trucks, as part of a classification-model proposal for an insurer. I moved an existing Excel workflow into Python and implemented supplied accident-vehicle classification criteria.

## My contribution
I developed **the analysis and classification code**, using Python and pandas. The classification criteria were provided rather than independently designed by me.

This is an example of translating business analysis and decision criteria into executable code, not a claim that I trained a new machine-learning model.
