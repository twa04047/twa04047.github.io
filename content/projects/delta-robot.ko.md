## 잡초 제거를 위한 로봇

2020년 경북대학교 SE-KNU 팀 프로젝트 **Advanced Weed Removal System**. 카메라로 대상을 인식하고 델타로봇의 엔드이펙터를 해당 위치로 이동시키는 제초 로봇을 목표로 했습니다. 이동형 프레임에 델타로봇을 탑재하고, 실내에서 반복적으로 동작을 확인할 수 있도록 컨베이어벨트 시험 환경도 제작했습니다.

저는 **CATIA를 이용한 델타로봇 설계와 로봇의 부속품 설계·제작**을 맡았습니다. 팀의 영상처리·모터 제어 시스템을 실제로 탑재하고 움직일 수 있는 기구부를 만드는 작업이었습니다.

## 직접 맡은 설계와 제작

파트 단위의 CAD 모델링부터 어셈블리 구성, 제작용 데이터 준비와 실물 제작까지 수행했습니다. 모터와 조인트의 장착 위치, 링크 연결 구조, 엔드이펙터가 움직일 공간을 함께 고려했습니다.

| 담당 범위 | 구체적인 작업 |
| --- | --- |
| 델타로봇 CAD 설계 | 상부 베이스, 링크, 엔드이펙터와 연결부를 CATIA로 모델링하고 어셈블리 구성 |
| 부속품 설계·제작 | 구매한 모터·조인트가 기구부에 결합되도록 부품을 설계하고 실물로 제작 |
| 지지 구조와 시험 장치 | 로봇을 지지하는 프로파일 프레임과 컨베이어 부품 설계·제작 |
| 제작 데이터 | CATPart·CATProduct, 도면, 3D 프린팅용 STL로 설계 내용 구체화 |

아래 영상처리와 역기구학·모터 제어는 **팀 전체 시스템**의 구성입니다. 이 페이지에서는 제가 맡은 기계 설계·제작과 시스템이 연결되는 지점을 함께 설명합니다.

## CATIA로 설계한 델타로봇

상부에 배치한 3개의 모터와 링크가 하나의 엔드이펙터를 움직이는 구조입니다. 베이스와 링크를 개별 파트로 설계하고, 조인트와 모터를 포함한 어셈블리에서 전체 형상을 구성했습니다.

![직접 설계한 델타로봇의 CAD 렌더링. 상부 베이스, 링크와 하부 엔드이펙터의 연결 구조.](../../../media/delta/delta-cad.jpg)
![당시 CATIA 어셈블리 화면. 개별 부품을 조합한 전체 로봇 모델.](../../../media/delta/cad-assembly.jpg)

2020년 10월 6일 회의록에는 RBLD8 조인트 부품이 도착한 뒤 **상부 암과 엔드이펙터의 치수를 수정한 과정**이 남아 있습니다. 설계를 실제 구매 부품과 맞추고 제작 가능한 형태로 구체화했습니다.

설계 치수는 팀의 역기구학 모델에도 연결됩니다. 최종 발표자료와 제어 코드에 사용한 주요 길이는 다음과 같습니다.

| 모델 파라미터 | 길이 |
| --- | ---: |
| 상부 링크 길이 L | 109.5 mm |
| 하부 평행 링크 길이 l | 246 mm |
| 상부 베이스의 기준 삼각형 한 변 | 123.94 mm |
| 엔드이펙터의 기준 삼각형 한 변 | 57.87 mm |

위 값은 당시 설계·제어 모델에 사용한 치수이며, 제작 오차나 위치 정밀도의 측정값은 아닙니다.

## 가동 범위를 고려한 프레임

델타로봇의 하부에는 엔드이펙터가 이동할 공간과 시험 대상이 지나갈 공간이 필요했습니다. 팀이 MATLAB으로 검토한 작업영역을 기준으로 프로파일 프레임의 크기와 로봇 장착 높이를 정했습니다.

![발표자료의 작업영역 계산 결과. 로봇 주변 구조의 치수를 정하기 위한 설계 기준으로 사용했습니다.](../../../media/delta/workspace.jpg)

![프로파일 프레임 설계 메모. 로봇의 수직 가동 범위, 장착 높이와 하부 여유 공간을 함께 검토했습니다.](../../../media/delta/gantry-sketch.jpg)

설계 메모에는 작업영역의 수직 거리와 모터 장착부 높이를 합산하고, 엔드이펙터와 지면 사이의 간격을 확보하는 계산이 남아 있습니다. 단품의 모양을 완성하는 것에 더해 **로봇 전체가 움직이는 공간을 확보하는 설계**가 필요했습니다.

## 부품 제작과 실물 조립

CAD 모델을 바탕으로 3D 프린팅 부품을 제작하고 모터·조인트·프로파일과 조립했습니다. 상부 베이스, Link1·Link2, 엔드이펙터의 STL과 일부 출력 작업 파일이 보관되어 있습니다.

![모터 장착부와 상부 베이스의 실물 조립 모습.](../../../media/delta/motor-mount.jpg)
![제작한 링크와 엔드이펙터를 연결한 조립 과정.](../../../media/delta/assembly-in-progress.jpg)

![프레임에 탑재한 델타로봇. 링크, 조인트와 엔드이펙터가 결합된 실제 제작물.](../../../media/delta/robot-detail.jpg)

설계 파일의 부품들이 하나의 구동 장치로 이어지는 과정을 경험했습니다. 부품 간 결합과 조립 공간을 CAD에서 함께 검토하는 일이 실물 제작의 중요한 조건이었습니다.

## 컨베이어로 만든 시험 환경

실제 밭의 이동 상황을 실내에서 모사하기 위해 컨베이어벨트를 제작했습니다. 벨트 베드, 지지대, 링과 모터 연결 부품의 CAD 파일 및 제작 도면이 남아 있습니다. 컨베이어의 구동은 팀의 Arduino·L298N·DC 모터 시스템과 연결했습니다.

![컨베이어벨트의 CAD 모델. 베드와 롤러 장착 구조를 설계했습니다.](../../../media/delta/conveyor-cad.jpg)
![제작한 컨베이어벨트와 잎 모양의 시험 대상.](../../../media/delta/conveyor-prototype.jpg)

2020년 10월 8일에는 컨베이어와 로봇 프레임의 조립을 논의했고, 10월 27일에는 컨베이어 수정·구동과 델타로봇의 이동영역 비교를 진행했습니다. 시험 장치까지 제작해 기구부와 제어를 함께 확인할 수 있는 환경을 마련했습니다.

## 팀 시스템과의 연결

완성한 기구부에는 Raspberry Pi 카메라와 3개의 Dynamixel MX-106 모터를 탑재했습니다. 팀의 제어 흐름은 다음과 같습니다.

1. **대상 인식:** 카메라 영상에 임계값 이진화를 적용하고, 윤곽선과 영상 모멘트에서 대상의 중심을 추출합니다.
2. **목표 위치 계산:** 영상에서 찾은 중심을 로봇이 움직일 좌표로 연결합니다.
3. **역기구학 계산:** 목표 좌표와 링크 치수로 각 모터의 회전각을 구하고, 축별 각도 범위를 제한합니다.
4. **모터 구동:** 위치·속도·체크섬을 포함한 패킷을 RS-485로 전달해 엔드이펙터를 움직입니다.

![로봇에 탑재한 화면에서 대상의 윤곽선과 중심을 확인하는 영상처리 시연.](../../../media/delta/vision-screen.jpg)

이 과정에서 기구 설계의 링크 길이와 기준 좌표가 제어 모델의 입력으로 사용됩니다. 설계와 소프트웨어가 동일한 치수와 동작 범위를 공유해야 전체 시스템을 연결할 수 있었습니다.

## 제작 결과와 다음 과제

**델타로봇과 부속품을 직접 설계·제작하고, 프레임과 컨베이어를 포함한 실물 시제품을 구성했습니다.** 최종 발표·시연 영상에는 CAD 설계, 제작물, 영상처리 화면과 엔드이펙터의 실제 동작이 함께 남아 있습니다.

이 프로젝트에서 쌓은 경험은 **CAD 모델을 제작·조립 가능한 부품으로 구체화하고, 가동 범위를 고려해 전체 기구를 구성하는 일**입니다. 이후 로봇의 인식과 제어를 이해하는 기반이 되었습니다.

검증 범위는 실내 시제품 시연입니다. 실제 밭에서의 잡초 제거율, 반복 위치 정밀도, 장시간 내구성은 별도 측정 결과가 없어 수치로 제시하지 않았습니다. 후속 설계에서는 이러한 항목을 시험 기준으로 삼아 기구의 개선 효과를 확인할 수 있습니다.
